# Job Portal

A full-stack job portal with dual-role authentication for Students and Recruiters.

## Features
- JWT-secured login with protected routes
- Recruiter dashboard — post jobs, manage applications
- Student dashboard — browse jobs, track applications
- Role-based access control throughout

## Tech Stack
React.js · Node.js · Express.js · MongoDB · JWT · Tailwind CSS

## Getting Started
```bash
# Clone the repo
git clone https://github.com/shikha-20171/job-portal.git

# Install frontend dependencies
cd job-portal && npm install

# Run frontend
npm run dev
```
